# AirWiki 0.3.0 candidate notes

The 0.3 beta contains the reading-focused desktop redesign and Windows AI-client
setup fixes. The [published v0.3.0-rc.2 release](https://github.com/airwiki/airwiki/releases/tag/v0.3.0-rc.2)
records available packages, the exact commit, checksums and platform trust state.

## What changed

- W essential unifies the application, native icons, documentation and landing
  around the existing linked-W geometry, with white strokes on a blue tile.
- A contextual sidebar keeps Library, To review, Wiki pages and Settings in
  reach. Resize or hide it for reading mode; the linked-W mark identifies Wikis.
- The page index and article scroll independently. Review state, freshness and
  warnings sit near the title, while expanded metadata follows the article.
- To review groups proposals by Wiki. Evidence and the editor sit side by side
  when space permits; compact windows use tabs. The action footer spans and
  reserves its own workspace row.
- Search remains a single row. If local AI needs attention, Search and
  Settings → General explain the next step.
- Settings has named sections and textual status. Onboarding remains usable
  in shorter windows and switches language immediately.
- Restarting restores the last valid local article and sidebar layout. Missing
  selections return to Library. Search text, remote browsing, consent and pending
  operations are not restored.
- Windows recognizes installed MSIX, native and npm AI clients, including saved
  PATH changes. Codex MSIX can connect without a separately installed CLI while
  preserving unrelated user configuration and explicit confirmation.

## Installation and recovery

Read the [installation guide](../install.md), including its backup and upgrade
instructions. The application version advances from 0.2.0 to 0.3.0 so installers
can recognize the update. Migration 0019 stores bounded local reading state;
older applications may refuse the newer database schema.

The published `v0.3.0-rc.2` channel is a non-Latest prerelease with a signed and
notarized macOS arm64 DMG and unsigned Windows x64 `en-US` and `es-ES` MSI files.
It supplies no updater manifest and does not enable the stable release channel.
The release records its exact build provenance and SHA-256 checksums.

## Validation scope

The redesign’s everyday reading, review, Settings and onboarding journeys passed
installed development-candidate checks on [macOS](../desktop-redesign-macos-validation.md)
and [Windows](../desktop-redesign-windows-validation.md), alongside automated
regression and visual checks. Those reports describe their tested candidates;
they are not a claim that the final signed/notarized release installers have
already passed acceptance.

The Windows AI-client fix also passed installed-candidate acceptance for Codex
and Claude detection, plus Codex cancellation, connection, disconnection and
conflict/recovery. [PR #120](https://github.com/airwiki/airwiki/pull/120) records
the tested candidate and limits: full Claude extension setup and a new Codex
conversation consuming the test configuration were outside that acceptance.

Specialized screen-reader acceptance remains deferred. Stable distribution and
its broader gates remain governed by the [release checklist](../release-checklist.md).

## Español

La versión 0.3 renueva la lectura, la navegación y la revisión: índice lateral
contextual, símbolo W enlazado, cola Para revisar, buscador de una fila y acciones
de revisión que ocupan todo su espacio. La identidad W esencial conserva ese
símbolo y unifica la app, sus iconos, la documentación y la landing. Ajustes
muestra estados claros y el inicio recuerda la última lectura local válida.
También corrige la detección de apps de IA instaladas en Windows y la
configuración de Codex MSIX.

Antes de actualizar, cierra AirWiki por completo y conserva una copia privada de
la aplicación y de sus datos. La beta publicada reúne macOS firmado y
notarizado con Windows como beta técnica sin firma; no es una versión estable ni
se instala mediante el actualizador. Consulta la release exacta para comprobar
qué paquetes están disponibles y verificar sus hashes.
